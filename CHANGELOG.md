# Changelog

## [1.0.3] - 2026-06-10

- Fixed optimizer miscompilations and a UTF-8 encoding crash on non-ASCII Brainfuck comments.
- Now tested on Python 3.10–3.14 (dropped 3.8 and 3.9).
- Improved test coverage; programs known to be unsupported are now marked xfail instead of erroring.

Initial public release.
